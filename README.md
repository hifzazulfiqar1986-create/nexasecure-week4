# NexaSecure Tech – Week 4

## Final Capstone Project – Shoe Store Admin Dashboard

### Overview

Week 4 was the final capstone phase of my Frontend Development Internship. I selected the Admin Dashboard project and developed a complete responsive dashboard for managing a shoe store.

### Project Pages

The dashboard includes:

* Admin Login
* Dashboard Overview
* Products
* Orders
* Customers
* Settings

### Work Completed

* Planned the complete dashboard structure and features.
* Created a clean project folder structure for:

  * HTML
  * CSS
  * JavaScript
  * Images
* Developed the Admin Login page.
* Created the Dashboard Overview page.
* Developed Products, Orders, Customers, and Settings pages.
* Added sidebar navigation between dashboard pages.
* Implemented product search and filtering.
* Added order status management:

  * Pending
  * Shipped
  * Delivered
* Added customer search functionality.
* Created editable profile/settings forms.
* Added responsive design for mobile, tablet, and desktop.
* Tested dashboard functionality systematically.
* Identified and fixed a dashboard statistics bug.
* Connected dashboard statistics with actual application data.
* Made Total Products update when products are deleted.
* Made Recent Orders display actual order data.
* Made Total Sales calculate from actual orders instead of fixed values.
* Created a professional README and documented the project.
* Uploaded the final project to GitHub.

### Technologies Used

* HTML5

### Key Features

* Responsive Admin Dashboard

### Testing & Debugging

During testing, I found that the dashboard statistics were showing fixed numbers instead of actual data. I analyzed the problem and modified the application so that dashboard statistics update according to product and order changes.

### What I Learned

I learned how to plan and develop a complete frontend application, organize a scalable project structure, implement dynamic data-driven features, manage application data using Local Storage, test application functionality, identify bugs, and fix real-world frontend issues.

### Outcome

The final capstone project combined the skills learned throughout the internship. I progressed from basic HTML/CSS pages to developing, testing, and documenting a complete responsive admin dashboard application.
